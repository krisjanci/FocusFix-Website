Install FocusFix on a Mac

FocusFix is an independently developed macOS app. The website build is signed with a Developer ID certificate and notarized by Apple. It requires macOS 14 or later.

Download FocusFix for macOS (ZIP) · Latest release and checksums

Install and open

  1. Download and unzip FocusFix-macOS.zip, then move FocusFix.app into Applications.
  2. Open FocusFix from Applications. macOS will identify the developer the first time you open it; review the prompt before continuing.
  3. Use the Quick tour to learn the controls with practice data. Choose whether to enable recording. Grant Input Monitoring only if you want automatic activity recording.

What is available

You can use manual and automatic recording, break reminders, session review and export, accounts, and private groups. Detailed recording uploads to the developer are currently disabled while that service is being prepared. Local recordings stay on your Mac unless you export them.

For integrity, compare the downloaded ZIP with SHA256SUMS.txt. The same release includes the matching source and GPL license.

Read the privacy details before recording. For a problem, open an issue without uploading recordings, credentials, or personal information.
