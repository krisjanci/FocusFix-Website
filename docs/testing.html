Test FocusFix on another Mac

This is a temporary build for testing while Apple Developer signing is being set up. It is ad hoc signed and not notarized by Apple. It is not a finished public release. Use it only on a Mac you control running macOS 14 or later.

Download the latest test build (ZIP) · Release notes and checksums

Install and open

  1. Download and unzip FocusFix-macOS.zip, then move FocusFix.app into Applications.
  2. Try to open the app. macOS may stop an app that Apple has not notarized. If you trust this exact download, use System Settings → Privacy & Security → Open Anyway, following Apple’s instructions. Do not turn off Gatekeeper for the whole Mac.
  3. In FocusFix, choose whether to enable recording. Grant Input Monitoring only if you want to test activity capture. You can start with the Quick tour, which uses practice data.

What this build can test

Try manual and automatic recording, breaks, session review and export, the account flow, and private groups. Detailed recording uploads to the developer are disabled because that service is not deployed. This build cannot test that sharing workflow. Local recordings stay on your Mac unless you export them.

For integrity, compare the downloaded ZIP with SHA256SUMS.txt. The same release includes the matching source and GPL license.

Read the privacy details before recording. For a problem, open an issue without uploading recordings, credentials, or personal information.
